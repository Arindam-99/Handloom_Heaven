## 🔗 Unsplash URL Format

All images use this URL pattern for consistent sizing:
```
https://images.unsplash.com/{PHOTO_ID}?w={WIDTH}&h={HEIGHT}&fit=crop
```

### Common Sizes Used
| Usage | Size |
|-------|------|
| Product cards | `400x400` |
| Category cards | `600x750` |
| Hero banners | `1200x400` |
| Hero slides | `800x600` |
| Artisan portraits | `400x400` |
| Discover cards | `600x400` |
| Review avatars | `100x100` |

---

## 📝 Notes

1. All product images are stored in MongoDB `Product.images[]` array
2. Images are seeded via `server/utils/seedFull.js`
3. Each product has 3 unique Unsplash images for the thumbnail gallery
4. Category images and hero banners are hardcoded in the React components
5. If any Unsplash URL breaks, the fallback `defaultImage` is used
