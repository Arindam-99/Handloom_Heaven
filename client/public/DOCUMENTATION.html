Project Overview

Handloom Haven is a full-stack e-commerce web application dedicated to authentic Arunachal Pradesh handloom, jewellery, traditional clothing, and handcrafted products. It connects local artisans and sellers with customers who value cultural heritage and ethical shopping.

Project Vision

The platform is designed to become a multi-vendor marketplace — similar in concept to Amazon or Meesho — but focused exclusively on products from Arunachal Pradesh. It celebrates the diverse tribal cultures, traditional weaving techniques, and artisanal craftsmanship of the region.

Core Objectives

  • Preserve Heritage: Showcase Arunachal Pradesh's traditional crafts to a global audience
  • Empower Artisans: Give local craftsmen and women a platform to sell directly to customers
  • Cultural Storytelling: Each product carries the story of its maker, material, and cultural significance
  • Modern Shopping: Provide a professional, trustworthy e-commerce experience
  • Multi-Vendor: Support multiple sellers with independent dashboards

Target Users

Data Flow

  1. Client Request: React sends HTTP request via Axios with JWT token in Authorization header
  2. Authentication: Express middleware verifies JWT and attaches user to request
  3. Route Handling: Express routes dispatch to appropriate controllers
  4. Business Logic: Controllers process data, validate inputs, interact with models
  5. Database Operations: Mongoose models perform CRUD operations on MongoDB
  6. Response: JSON response sent back to client, Redux store updated
  7. UI Update: React components re-render with new state

Authentication System

JWT-based authentication with role-based access control for Customer, Seller, and Admin users.

How It Works

  1. Registration: User submits name, email, password → Password hashed with bcrypt → Saved to MongoDB → JWT token generated
  2. Login: User submits email + password → Password verified → JWT token returned → Stored in localStorage
  3. Protected Routes: Axios interceptor attaches Authorization: Bearer <token> header → Middleware verifies JWT → Attaches user to request
  4. Role Authorization: Route-level middleware checks user.role against allowed roles (user, seller, admin)

Frontend Auth Flow

// services/api.js — Axios interceptor
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

Backend Auth Middleware

// middleware/auth.js
const protect = async (req, res, next) => {
  // 1. Extract token from Authorization header
  // 2. Verify JWT with secret key
  // 3. Find user in database
  // 4. Attach user to req.user
  // 5. Call next()
};

const authorize = (...roles) => {
  return (req, res, next) => {
    if (!roles.includes(req.user.role)) {
      return res.status(403).json({ message: 'Not authorized' });
    }
    next();
  };
};

How to Run the Project

Step-by-step guide to set up and run the development environment.

Prerequisites

  • Node.js v18+ installed
  • MongoDB Atlas account (or local MongoDB)
  • Git installed

Setup Steps

# 1. Clone the repository
git clone https://github.com/your-repo/handloom-haven.git
cd handloom-haven

# 2. Install server dependencies
cd server
npm install

# 3. Configure environment variables
# Create .env file in server/ with MongoDB URI and JWT secret

# 4. Seed the database with 46 products
node utils/seedFull.js
node utils/addMoreProducts.js

# 5. Start the backend server
npm run dev
# Server runs on http://localhost:5000

# 6. In a new terminal, install client dependencies
cd ../client
npm install

# 7. Start the frontend dev server
npm run dev
# Client runs on http://localhost:5173
